How to Set a Preset ▼
Presets are saved directly on the speaker — each button (1–6) remembers whatever was playing when you held it down.

Step 1 — Start playing the station, playlist, or source you want to save.
Step 2 — On the speaker itself, press and hold the preset button (1–6) for about 3 seconds until you hear a chime.
Step 3 — The button is now saved. Press it briefly at any time to play that station again.

Tip — If you use Custom Radio Stations (see below), play the station from the Presets tab first so it is the active source, then hold the preset button on the speaker to save it.

After saving — Click Backup Now below to save a local copy so your presets survive the Bose cloud shutdown on 6 May 2026.

Custom Radio Stations ▼

Add your own internet radio streams. These are served locally and don't need the Bose cloud.

How to add a Custom Station ▼
Custom stations let you play any internet radio stream that has a direct HTTP audio URL — no Bose cloud required.

Step 1 — Find a direct stream URL for the station. Most public broadcasters publish these; search for "[station name] stream URL m3u" to find one.
Step 2 — Enter a name, paste the URL, and optionally add an album art URL below, then click Add Station.
Step 3 — The station will appear in the list. Click Play to start it on the active speaker.
Step 4 — While it's playing, hold a preset button on the speaker to save it — see How to Set a Preset above.

Note — Stream URLs must start with http:// (not https) as the SoundTouch firmware does not support TLS streams.
